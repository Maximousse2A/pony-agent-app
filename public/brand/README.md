# Logos Pony

`pony-purple.svg` et `pony-white.svg` reprennent les SVG téléchargeables générés par le **kit média officiel Pony** :

https://getapony.com/presse#KIT-MEDIA

Le chemin vectoriel, le `viewBox="0 0 124 43"` et les couleurs sont ceux de la génération SVG publiée sur cette page. Seuls les noms des fichiers locaux sont adaptés. Les fichiers ont été récupérés le 12 novembre 2026 et leur structure XML a été vérifiée.

Le kit décrit ces logos comme prêts à intégrer dans des articles et supports. Cette provenance n’est pas une déclaration de licence open source ni un transfert de marque. Pony conserve ses droits sur sa marque. Leur utilisation ici identifie le sujet du prototype de case study ; elle n’établit pas une affiliation ou une application officielle.

- Violet officiel : `#321E64`.
- Blanc : `white` (soit `#FFFFFF`).
